Global attributes

Global attributes can be used with almost all HTML elements.

They provide common information or behavior to elements.

They are not limited to a specific HTML tag.

They are not limited to a specific HTML tag.

examlpe: id ,class ,style ,title ,lang ,hidden ,data

Local Attributes

Local attributes are also called element-specific attributes.

They are used only with specific HTML elements.

They provide special information or functionality to that element.

example: href ,src ,alt ,action ,method ,type

Favorite Icon

It is a small icon associated with a website.

It appears in the browser tab next to the website name.

t can also appear in bookmarks and browser history.

It helps users identify a website easily.

Usually, a favicon is added using the link element inside the head.

Common image formats are: .ico, .png, and .svg

Attributes

Attributes provide additional information about an HTML element.

They are written inside the opening tag.

Attributes usually follow the format name="value".

They can change the behavior, appearance, or meaning of an element.

An element can have multiple attributes.

attributes include: id, class, style, href, src, and alt.

There are mainly two types of attributes: 1.Global Attributes 2.Local Attributes
